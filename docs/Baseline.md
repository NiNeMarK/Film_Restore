วัดเมื่อ 6 พ.ย. 2026 ด้วย preset ค่าเริ่มต้น (denoise 0.4–0.5, upscale 2, face 0.7)
ทุกค่าคำนวณเทียบกับภาพอ้างอิง Kodak 24 ภาพ — ตัวเลขคุณภาพ **ตรงกันทั้ง CPU และ GPU**
(torch 2.15.0+cpu และ 2.14.1+cu126 บน RTX 3060) ต่างกันแค่เวลาที่ใช้

ชุดทดสอบสร้างด้วย `python backend/tools/make_testset.py` (fixed seed 20260101):

- `testset/negative/in` — เนกาทีฟสี + มาสก์ส้มฐานฟิล์ม (เข้าคู่กับ `color_negative`)

## อ่านผล

- **SSIM ของ `negative_input` ติดลบ** เป็นเรื่องปกติ เพราะภาพเนกาทีฟกลับสีกับต้นฉบับ (สหสัมพันธ์ย้อนทาง) ค่าที่ใช้เทียบคือแถว `negative → color_negative`
- **faded_color** ได้ PSNR เพิ่ม ~3.7 dB และสีสดขึ้นมาก (colorfulness 31 → 51) แต่ LPIPS ดีขึ้นเล็กน้อยเท่านั้น — ขั้นแก้สีช่วยเรื่องคอนทราสต์/สี แต่ยังไม่ได้คืนรายละเอียดความถี่สูง
- **color_negative** ได้ SSIM 0.85 และ LPIPS 0.19 — การกลับสีแม่นกว่าการซ่อมภาพพิมพ์ที่ซีด
- เวลาต่อภาพ (768×512, preset ค่าเริ่มต้น): **GPU ~1.4 วิ/ภาพ**, CPU ~15.9 วิ/ภาพ (≈8–11 เท่า) — ใช้เทียบเวลาปรับ pipeline

## รันซ้ำ

```bash
python backend/tools/make_testset.py
python backend/tools/evaluate.py --input testset/faded/in --reference testset/ref \
  --preset faded_color --out backend/outputs/baseline/faded --lpips
python backend/tools/evaluate.py --input testset/faded/in --reference testset/ref \
  --no-pipeline --out backend/outputs/baseline/faded_input --lpips
```
